# WanderPing maps

Offline city maps for the WanderPing app, one PMTiles file per city (`<city>.pmtiles`), each in its own release
(`<city>-<date>`). The app lists the file of every city in its catalog (`cities.json`, field `offlineMap`).

Map data © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright), available under the
[Open Database License (ODbL)](https://opendatacommons.org/licenses/odbl/). Vector tiles extracted from the
[Protomaps](https://protomaps.com) basemap build.

## Catalog

The app's catalog of cities, attractions and trips, a database derived from OpenStreetMap, is published here under the
ODbL 1.0, in the `catalog-<version>` releases. Contents, sources and licenses: [CATALOG.md](CATALOG.md).
